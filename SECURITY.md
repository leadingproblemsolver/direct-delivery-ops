# Security, Privacy, and Relationship Safety

- Public sources only unless permission is explicit and recorded.
- No authentication circumvention, paywall bypass, private-community scraping, bulk personal-data enrichment, or automated outbound.
- Minimize stored personal data and preserve only what is necessary to verify the artifact.
- Treat exact quotes, handles, and contact surfaces as potentially sensitive.
- Human approval cannot be delegated to an LLM or browser agent.
